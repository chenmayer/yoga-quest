# Yoga Quest

אפליקציית תרגול עצמית לקורס מורים ליוגה. ממשק בעברית, מתאים לטלפון.

## היכולות הקיימות

- טריוויה לפי נושא, שיעור, שאלות שלא נצפו, שאלות מעורבבות וחזרה מתוזמנת
- התאמות, השלמות, סידור רצפים וזיהוי תנוחות/התאמות
- **שמירת סבב פעיל**: יציאה וחזרה לאותה שאלה, גם אחרי רענון הדף
- **כרטיסיות סנסקריט דו־כיווניות**: סנסקריט ← עברית ולהפך, 57 מושגים
- **ספריית שיעורים**: סיכומי 10.11, 13.11 ו־17.11, לפי נושאים ובקישור לתרגול
- XP, היסטוריית שאלות, פרופילים מקומיים ושיעורי בית

## מבנה הפרויקט

| קובץ | תפקיד |
|---|---|
| `index.html` | מעטפת HTML וטעינת הקבצים בסדר הנכון |
| `assets/styles.css` | עיצוב מובייל ו־RTL |
| `assets/app.js` | ניווט, מנועי תרגול, שמירת מצב וממשק |
| `data/questions.js` | מאגר שאלות הטריוויה; יש לשמור על מזהי השאלות בעת עדכון |
| `data/study.js` | סיכומי שיעורים וכרטיסיות סנסקריט |
| `data/games.js` | תוכן משחקי התאמה, השלמות, רצפים ותנוחות |
| `data/curriculum.js` | מפת כיסוי פנימית ומטלות הקורס |
| `tests/smoke.test.cjs` | בדיקות רגרסיה ב־Node |

## הוספת שיעור

1. לעיין בסיכום המקורי ולנסח את עיקרי הדברים ב־`LESSON_NOTES` בקובץ `data/study.js` עם תאריך, מקור וסעיפים. אין להשלים כתב יד לא ברור בניחוש.
2. להוסיף שאלות ב־`data/questions.js` עם מזהי `id` חדשים, `lesson`, `topic`, ארבע אפשרויות, `answer` ו־`why`.
3. להרחיב את `SANSKRIT_CARDS` אם נלמד מונח חדש; כל כרטיסייה צריכה מזהה ייחודי.
4. לעדכן את `COVERAGE_UNITS` ב־`data/curriculum.js` כדי לעקוב אחרי כיסוי החומר, בלי לחשוף את המפה ב־UI.
5. להריץ `node --test tests/*.test.cjs`, לבדוק את גרסת הניסיון בטלפון ואז לפרסם.

## שמירת נתונים

האתר משתמש במפתח `localStorage` הקיים, `yoga-quest-v1`, ולא מוחק היסטוריית תרגול ישנה. מצב השאלון ומצב הכרטיסיות נשמרים בנפרד **לכל פרופיל מקומי**. בסיום סבב הוא מוסר מהתור השמור, אך XP והיסטוריה נשמרים.

**אין עדיין סנכרון בין מכשירים, חשבונות אמיתיים או שחזור אוטומטי אחרי ניקוי נתוני דפדפן.** אפשר להפיק גיבוי JSON מלשונית השיעורים > מאגר השאלות וייבוא חומר. זהו ייצוא בלבד, לא מנגנון שחזור של התקדמות בשלב הזה.

## בדיקות

```bash
node --test tests/*.test.cjs
```

הבדיקות מכסות טעינת קבצים, בחירת משחק, מיפוי שאלות, חזרה לתרגול אחרי טעינה מחדש, מניעת ניקוד כפול, כרטיסיות דו־כיווניות, שיעורי בית וספריית שיעורים. מומלץ לבצע גם בדיקת דפדפן אמיתי בנייד לפני פרסום.
