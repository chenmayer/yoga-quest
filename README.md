# Yoga Quest — גרסת פיתוח 1.1

גרסת הפיתוח הזו מוסיפה תרגולי התאמה, השלמת מושגים, סידור רצפים וזיהוי תנוחות באמצעות איורים סכמטיים, לצד חזרות מתוזמנות.

## בדיקות
```bash
node --test tests/*.test.cjs
```

## שמירת נתונים
הגרסה משמרת את מפתח `localStorage` הקיים (`yoga-quest-v1`) ואת הפרופילים, התשובות וה-XP.

## פרסום
יש לבדוק את גרסת ה-Deploy Preview בטלפון לפני מיזוג ל-`main`. אין לבצע מיזוג לפני אישור הבדיקות.
